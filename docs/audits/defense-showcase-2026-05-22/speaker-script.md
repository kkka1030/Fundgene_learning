# FundGene 答辩讲稿草案

Date: 2026-05-22
Status: Draft v1

## 60 秒版

各位老师好，我们的项目是 FundGene，一个面向基金投资新手的 Agent Command Center。

新手投资者真正困难的地方，不是没有信息，而是信息太多之后不知道怎么形成安全判断。新闻、政策、组合波动、课程学习和个人情绪往往是割裂的，用户很容易先被标题带动，再去找理由解释自己的操作。

FundGene 的设计目标是反过来：先解释，再判断，最后才确认。用户进入产品后，首页不是普通的数据看板，而是 Agent 已经整理好的今日简报。它会基于用户授权的画像、组合、资讯、学习和训练记录，给出今天最重要的一条判断、对应证据、一个安全下一步，以及明确不能做什么。

如果用户想继续追问，可以把任务交给 Agent 工作区。比如“最近新闻对我的资产有什么影响？”系统会读取画像、检查组合、整理新闻影响路径，再输出面向新手的解释和边界。它不是自由聊天，而是可追踪的工具链工作流。

此外，资讯页会把政策新闻拆成事实、影响路径和不确定性；模拟训练会让用户在历史情境中写下理由、担忧和冲动控制计划；自动任务只负责后台读取、整理和提醒，真正影响长期画像的内容必须进入资料中心等待用户确认。

所以 FundGene 不是交易机器人，也不承诺收益。它的核心价值是把基金投资新手的日常判断变成一个有证据、有边界、可复盘的训练闭环。

## 3 分钟版

各位老师好，我们的项目是 FundGene，一个面向基金投资新手的 Agent Command Center。

我们一开始想解决的问题是：新手投资者不是单纯缺少信息。现在信息非常多，真正的问题是新闻、政策、基金组合、课程学习和个人行为之间没有被组织起来。用户看到一条政策新闻，可能不知道它和自己的组合有什么关系；看到基金回撤，可能先焦虑，再冲动调整；学过的风险概念，也很难回到真实组合里使用。

所以 FundGene 没有把产品做成普通聊天机器人，也没有做成交易自动化系统。我们的边界很明确：不连接券商、不执行买卖、不承诺收益。我们做的是一个纪律化的投资教练 Agent，让用户先理解、再判断、最后确认。

第一个核心页面是 Today，也就是今日简报。它是默认首页，代表 Agent 已经替用户做完第一轮整理。系统会读取用户授权的画像、组合报告、资讯政策、学习进度、模拟训练和行为证据，压缩成一条今天最重要的判断。比如这里的判断是“今天先检查组合集中度，不急着响应单条新闻”。它同时给出判断依据、安全下一步，以及明确的安全边界。

第二个核心页面是 Agent Workspace。用户可以直接从 Today 带着上下文追问，也可以输入一个任务，比如“最近新闻对我的资产有什么影响？”这里我们希望展示的不是神秘的 AI 回答，而是清晰的工作过程：读取画像、检查组合、整理资讯影响、准备安全下一步。最终回答也不会直接变成买卖建议，而是解释影响路径、不确定性和用户可以先做的安全检查。

第三个特色是资讯影响分析。传统资讯页容易变成新闻列表，而 FundGene 会把一条政策或市场信息拆成三件事：发生了什么、和我的组合可能有什么关系、哪些地方仍然不确定。这样用户不会把标题直接当作操作理由，而是先理解它和自己资产结构的关系。

第四个特色是模拟训练。我们不是只做问答，而是训练用户在真实压力情境下的判断纪律。在历史情境中，用户要选择动作，并写下理由、担忧和冲动控制计划。系统生成复盘和行为候选线索，但不会直接改写用户画像。真正长期保存的内容，需要后续证据和用户确认。

第五个特色是自动任务和资料中心。自动任务可以定期整理每日简报、组合巡检、资讯影响和行为观察，但它只做读取、分析、提醒和待确认建议。Profile 资料中心负责展示授权范围、上下文完整度和待确认资料。也就是说，高影响状态变化不会被模型静默写入，而是通过用户确认进入长期上下文。

从工程实现上，FundGene 的关键不是多做几个页面，而是做出一个可追踪的 Agent Runtime。前端是 Command Center，后端负责会话、权限、工具执行、结构化输出、运行事件、证据和待确认写回。业务真相和安全边界在后端，前端负责把流程展示得对新手可理解。

最后，答辩展示素材也做成了可重复流水线。我们用 Playwright 自动驱动页面，用确定性的演示数据录制功能片段，再用 ffmpeg 转成 MP4 和 GIF。这样后续每次改前端，都可以重新生成素材，而不是手动摆拍。

总结来说，FundGene 的价值是把新手基金投资从“看信息后凭感觉操作”，转成“Agent 整理上下文、用户理解判断、系统给出安全下一步、关键变化由用户确认”的闭环。它不是交易机器人，而是一个有证据、有边界、有训练机制的投资教练 Agent。

## Q&A Hooks

### 如果老师问：为什么不用普通大模型聊天？

普通聊天只能回答当下问题，但 FundGene 需要长期上下文、组合状态、学习进度、行为证据和安全写回。我们的重点是把模型放进一个受控工作流：先查授权上下文，再调用领域工具，最后输出结构化答案和待确认动作。

### 如果老师问：这会不会变成荐股或交易系统？

不会。项目边界明确禁止交易执行、收益承诺和强操作建议。系统只做解释、训练、检查和待确认建议，所有高影响状态变化都需要用户确认。

### 如果老师问：项目技术亮点是什么？

技术亮点是 Agent Runtime 和产品闭环结合：单一用户入口、后端工具链、结构化输出、运行事件追踪、证据引用、待确认写回、自动任务和评测验证。它不是单页 demo，而是一个可持续扩展的工作台架构。

### 如果老师问：演示素材怎么保证不是手动摆拍？

我们已经把录制做成 Playwright 自动脚本：固定演示数据、自动打开路由、自动点击和录屏，再用 ffmpeg 生成 MP4/GIF。展示素材可以重复生成，也可以随产品改动更新。
